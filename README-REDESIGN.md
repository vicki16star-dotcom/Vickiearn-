# Vickiearn — New Design

Vickiearn is being completely redesigned. The legacy product flow is paused while the new experience is built.

## Redesign direction
- Clean, modern landing page
- Clear product positioning
- Mobile-first responsive layout
- Simple navigation and calls to action
- No live financial/payout functionality in the redesign until separately reviewed and enabled

## Status
Backend is currently paused. Frontend redesign is in progress.
